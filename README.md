# ansh101112.github.io

My portfolio. Hand-written HTML and CSS — no framework, no build step, no
dependencies.

Live at **https://ansh101112.github.io**

```
index.html    the whole site
styles.css    dark by default, light when the OS asks
.nojekyll     serve the files as-is instead of running them through Jekyll
```

GitHub Pages serves this branch directly, so there is nothing to build and
nothing to deploy: push and it is live.
